# ADR 0001: L0 단원 지도의 범위와 단원 id

상태: 제안 (사용자 결정 대기). 날짜: 2026-11-07. 작성: curriculum-architect.

## 배경

L0 "영어의 시작"의 졸업 과제는 "3~5단어 문장의 주어·동사·목적어 표시"이다. DESIGN 3-1의 L0 핵심 내용에는 "발음 기초, 주어·동사, be동사·일반동사, 부정·의문"이 함께 있다. 승인된 L0-U05는 주어·동사·목적어 찾기만 다루고, 명세의 `unverified`가 U01~U04를 "정의되지 않음"으로 남겼다. 그래서 L0의 단원 수와 순서, 단원 id를 정해야 한다.

## 선택지

1. L0에 be동사·부정·의문(U06~U08)까지 넣는다. 장점: DESIGN 3-1 L0 목록과 맞는다. 단점: 졸업 과제 범위를 넘고, 단원이 8개라 4~6주 기간이 빠듯하다.
2. be동사·부정·의문을 L1로 미루고 L0은 U01~U05(5단원)로 끝낸다. 장점: 졸업 과제와 맞는다. 단점: DESIGN 3-1 L0 목록과 맞지 않아 설계서를 고쳐야 한다.
3. 단원 수는 그대로 두고 U06~U08을 "L0 확장"으로 표시해 졸업 판정과 분리한다. 장점: 설계서를 바꾸지 않는다. 단점: 단계 구조가 복잡해진다.

## 결정 (제안)

- 단원 id는 L0-U01~U04(선수 단원, U05 명세가 예고한 번호)와 L0-U06~U08(신규)로 한다. 사용자 승인이 필요하다.
- 발음 기초는 단원에서 뺀다(CLAUDE.md 범위).
- 선택지 3(L0 확장 표시)을 임시로 쓰고, 사용자가 1 또는 2를 고르면 바꾼다. 설계자는 2를 더 권한다. 졸업 과제가 S·V·O이므로 L0 졸업 판정이 be·부정·의문까지 요구하면 학생이 졸업 과제 없이 단계를 넘는 것처럼 보이기 때문이다.

## 근거

- 졸업 과제와 단계 내용의 불일치는 DESIGN 3-1에 있다(L0 핵심 내용 ≠ 졸업 과제). [근거]
- 처음 배우는 학생 기준으로 주어·동사 판단 전에 명사·동사 구분이 있어야 한다. [가정, 학생 데이터 없음]
- 단원 8개의 기간 추정(단원당 3~5일)은 설계서의 4~6주 추정에 맞춘 것이다. [가정]

## 사용자 승인이 필요한 것

1. 단원 id L0-U01~U06~U08 사용(신규 id 생성).
2. L0 범위(선택지 1, 2, 3 중 택일).
3. 스키마 값 추가: `sentenceUse`에 빈칸 형태 문항용 값("blank")을 넣을지. 지금은 U04 형태 문항을 "building"으로 임시 생성한다. 스키마 변경이므로 승인 사항이다.
4. 인터랙션: role_tagging에서 한 역할만 표시하는 모드를 쓸지(13장에 없음).

## 미검증

- 공식 교육과정 문서로 L0 단원 구성을 확인하지 못했다.
- DESIGN 3-2 "문법 단원은 SentenceAnalyzer 연습으로 끝난다"의 "분석기 과제" 형태(role_tagging 한 역할 표시, 문장 조립)가 설계 의도에 맞는지는 해석 문제다.
